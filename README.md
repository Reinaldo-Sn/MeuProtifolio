# Portfólio — Reinaldo Sn

Portfólio pessoal desenvolvido com React, TypeScript e Styled Components.

## Tecnologias

- React 18
- TypeScript
- Styled Components
- React Router DOM v6
- React Icons
- Vite

## Páginas

- **Home** — Apresentação pessoal com links para About e Contact
- **About** — Descrição sobre mim e experiências
- **Projects** — Projetos publicados buscados dinamicamente via GitHub API
- **Contact** — Links para GitHub e LinkedIn, e stack de tecnologias

## Layout

- **Desktop** (> 1024px): navbar lateral fixa com 280px de largura
- **Tablet** (768px – 1024px): navbar no topo com links visíveis
- **Mobile** (< 768px): navbar no topo com menu hambúrguer

## Como rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
